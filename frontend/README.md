# 可选前端：本地结果查看器

用浏览器打开 index.html，再选择后端生成的 result.json。无需 npm、Python、API、模型密钥或构建工具。
文件只在浏览器本地读取，不上传，不执行分析任务。服务器压力大时完全不部署 frontend 目录即可。
没有自动监测 CPU 或停启服务：前端与分析引擎没有常驻依赖，是否打开由用户选择。

若浏览器安全策略禁止 file 页面运行脚本，可在个人电脑显式启动静态服务：

    python -m http.server 8765 --bind 127.0.0.1 --directory frontend

仅用于本地开发，不要暴露到公网，不要把整个仓库作为静态服务目录。
不提供上传分析、登录、任务调度或编辑报告功能。文件上限 20 MB。
